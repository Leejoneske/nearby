Features

Everything you need to find a place worth going

Real opening hours, honest prices and reviews you can read before you leave the house.

Filter until it fits

Sort by rating, distance or price. Narrow to what is open now, then stop looking.

See it on the map

Every result as a pin, colour-coded by category. Tap one and the details slide up.

Know before you go

Save for later

How it works

One app, from curious to on your way

Type what you want or pick a category. Results are ranked by how well reviewed a place is and how close it is to you.

Switch to the map to see how far each option really is. Filter to one category and the rest drop away.

Read the reviews, check the hours, call ahead if you want. Then take the directions and go.

Save the places that turned out well, and find them again without searching twice.

How to install
  1. Tap the download button and let the file finish saving.
  2. Open it. Android will ask permission to install from this source the first time — allow it, then press Install.
  3. You may see a Play Protect warning because the app is not on the Play Store yet. Choose Install anyway.

Android 8 or newer. iPhone cannot install APKs — iOS apps can only come from the App Store or TestFlight.
